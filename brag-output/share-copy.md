## Medium (LinkedIn / GitHub / newsletter)

A QR code is usually a utility graphic. QR Volde treats it as architecture: a giant 3D QR unfolds into a Kathmandu-style chowk with a tiered pagoda, a tea stall, a dhunge dhara, prayer flags, a bus, and one small dog. Then the Studio gives you a flat, scannable code of your own.

It is free, client-side, and has no backend. The 3D code is the artwork; the flat Studio code is the one to scan.

Watch the 20-second launch film: https://harmless-beep.github.io/qr-volde/launch.html

Try the world: https://harmless-beep.github.io/qr-volde/
